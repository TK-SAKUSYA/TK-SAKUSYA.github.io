# SNS LIFE

架空のSNSアカウントを運営し、投稿・交流・フォロワー獲得・収益化を目指すブラウザゲームです。

## 公開URL

https://tk-sakusya.github.io/SNS-LIFE/

## 操作方法

1. 初回起動時にプレイヤー名・ユーザーID・アイコンを設定します。
2. ホームの入力欄から投稿します。
3. 投稿へのいいね・コメント、投稿削除ができます。
4. 検索・トレンド画面で投稿を検索し、人気投稿やおすすめユーザーを確認できます。
5. 通知・DM・プロフィール・分析・設定をナビゲーションから開けます。
6. NPCはゲーム内時間に合わせて投稿し、プレイヤーの投稿に反応します。

## 実装機能

- スマートフォン／タブレット／PC向けレスポンシブUI
- スマートフォン下部ナビゲーション、PCサイドナビゲーション
- ライトモード／ダークモード
- プレイヤー名、ユーザーID、プロフィール画像、自己紹介の編集
- 投稿作成、削除、いいね、コメント、閲覧数、投稿時刻
- NPC 15アカウント（一般ユーザー、ファン、アンチ、インフルエンサー、企業、ニュース、ネタ投稿職人など）
- NPCの自動投稿、いいね、コメント、フォロー反応
- トレンド、投稿検索、人気投稿ランキング、おすすめユーザー
- 通知、NPCとのDM
- バズ、炎上、トレンド入り、有名人の反応、フォロワー増減などのイベント
- フォロワー数に応じた6段階ランク
- 広告収益、企業案件、収益履歴、ゲーム内コイン
- localStorageによる自動セーブ
- JSON形式のセーブデータ書き出し／読み込み
- ネットワーク接続なしでも基本的なゲーム進行が可能（ブラウザ内保存）

## セーブデータ

セーブデータは利用中のブラウザのlocalStorageに保存されます。ブラウザのデータ削除や別端末への移行では消える可能性があるため、設定画面からJSONバックアップを保存してください。

## 技術
