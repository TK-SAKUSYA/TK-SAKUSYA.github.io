EXPERIMENTAL · VERSION 0.1.0

M-AI

A Minecraft AI player that starts without supplied Minecraft guides and builds a record of what it observes and experiences.

What is M-AI?

M-AI is an open-source experiment in observation-first Minecraft agents. It connects to a local Minecraft Java server, observes the world through opaque sensor identifiers, stores experience, and can use a local Ollama model to choose limited actions.

  • Local-first: agent memory stays on your computer.
  • Human operator takes priority over autonomous behavior.
  • No Minecraft wiki, recipe book, or strategy database is bundled.
  • Designed as a foundation for future learning, cooperation, and civilization systems.

Important limitations

This is an early experimental release, not a finished autonomous civilization. Minecraft 26.3 compatibility has not yet been verified in a live end-to-end test. A language model's pretrained knowledge cannot be erased, so “zero knowledge” is an observation-first design goal rather than a mathematical guarantee.

Use only an isolated local test server. Offline-mode servers must never be exposed to the internet.
