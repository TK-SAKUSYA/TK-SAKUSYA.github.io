EXPERIMENTAL · VERSION 0.13.0

M-AI

観察と経験から学び、それぞれの名前と性格を持って活動するMinecraft AIプレイヤーシステム。

第十二回アップデート

  • Fabric Modのビルド成果物名を統一
  • ビルド後にMod本体が1個だけ生成されたか検査
  • 導入用JAR・導入手順・SHA-256チェックサムを一つの成果物にまとめる
  • GitHub Actionsから導入パッケージを取得可能にする
  • 成果物の保存期間は30日
  • 実際のビルド成功とゲーム内動作はまだ確認が必要

第十一回アップデート

  • Minecraftから届いた観察データをローカルPCに保存
  • 最新の観察内容・受信時刻・接続元を記録
  • 空データや不正な観察メッセージを拒否
  • 保存に失敗した場合はエラーを返す
  • 保存先は data/bridge/latest-observation.json
  • AI判断とゲーム操作の接続はまだ未実装

第十回アップデート

  • Minecraft Java 26.3用のFabricクライアントModを追加
  • Minecraft起動時にローカルM-AI通信ブリッジへ接続
  • ワールド内にいる間、5秒ごとにプレイヤー座標を送信
  • 通信処理はゲーム本体とは別スレッドで実行
  • GitHub ActionsでModのビルドを自動化
  • AIによる移動・採掘・建築などの操作はまだ未実装

第九回アップデート

  • 通常のシングルプレイ連携に向けたローカル通信ブリッジを追加
  • 127.0.0.1限定のTCP通信・JSON Lines形式・接続確認を実装
  • 観察・チャット・状態・実行結果を受け取る基礎プロトコルを用意
  • この段階ではMinecraftの操作やAI判断はまだ未接続

第八回アップデート

  • 小さな壁（横3×高さ2）または柱（高さ3）を建築
  • 必要なブロック数・設置先の空き・足場を確認
  • 操作担当者の明示的な指示が必要で、途中中断にも対応

第七回アップデート

  • 操作担当者の明示的な指示でブロックを1個設置
  • 所持アイテム・設置先の空き・隣接する足場を確認
  • 保護対象ブロックや液体などへの設置を回避

第六回アップデート

  • 操作担当者の明示的な指示でアイテムをクラフト
  • 所持素材とレシピを確認してから実行
  • 近くに作業台があれば利用
  • 1回の指示につき最大4回分に制限

第五回アップデート

  • 操作担当者の明示的な指示で1ブロックを採掘
  • 採掘範囲・到達可能性・ブロック状態を確認
  • 採掘中の操作担当者による中断に対応

第四回アップデート

  • 操作担当者を全AIで共通化
  • 最初に !mai claim を実行したプレイヤーが全AIの操作担当者になる
  • AIごとに登録し直さず、全AIへの一括指示・停止・再開・記憶リセットが可能
  • 移動中も約150ミリ秒ごとに足場と障害物を確認
  • 進行方向に壁がある場合は移動を中断
  • 次の足場がない場合は移動を中断
  • 安全確認の情報が不足している場合も移動を中断
  • 人間の操作担当者による中断機能を維持
  • AI自身が決めた名前・自己紹介・性格・個別記憶を維持

重要な制限

第十回でFabricクライアントModと座標送信を実装し、第十一回で受信した最新観察データをPC内に保存できるようにしました。AI判断とゲーム操作の接続、AIプレイヤーの生成、実ワールドでの動作確認は未完了です。

今回の移動確認は簡易的な足場・障害物チェックです。完全な経路探索や、あらゆる危険の回避を保証するものではありません。

日記を書くAIには、あらかじめ本と羽ペンをインベントリに入れておく必要があります。言語モデルの事前学習知識そのものを消去することはできません。
