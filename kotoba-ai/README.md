# ことばAI 🧠

会話から単語を覚え、覚えた言葉や過去の会話記録を使って返答を組み立てる学習プログラムです。

## 起動方法
GitHub Pagesで公開ページを開くだけで使えます。ローカルでは `index.html` をブラウザで開いてください。

## 主な機能
- 会話から語彙を自動登録
- 過去の発言との類似度を使った返答
- 一致する記録がないときも、学習済みの単語から返答を生成
- LINE風のチャットUI
- ライトモード／ダークモード切り替え（設定から変更・自動保存）
- ブラウザへの学習データ自動保存
- 学習データのJSON書き出し・読み込み・リセット

## 大切な仕様
これは大規模言語モデルではありません。単語の意味を完全に理解したり、未知の質問に正しい知識で答えたりはできません。会話中の語彙と過去の発言の類似度を使う実験的なプログラムです。学習データとテーマ設定は利用中のブラウザ内に保存され、別の端末やブラウザとは自動同期されません。

## ファイル構成
- `index.html` : 画面
- `style.css` : LINE風デザインとテーマ
- `app.js` : 学習・返答ロジック
