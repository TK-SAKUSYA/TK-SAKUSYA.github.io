# YouTube Clone Demo

個人制作のYouTube風UIデモです。YouTube公式のサービスではありません。

## 公開ページ
https://TK-SAKUSYA.github.io/youtube-clone/

## 機能
- 動画一覧とキーワード検索
- カテゴリーフィルター
- 動画プレイヤー（YouTube埋め込み）
- ショート風一覧
- 高評価、後で見る、チャンネル登録のデモ操作
- 動画IDを一覧に追加するフォーム

## 注意
- 実際のYouTubeアカウントとは連携しません。
- 追加データや操作状態はデモ用で、ページ再読み込み後に保存されません。
- 「動画を一覧に追加」は動画ファイルのアップロードではありません。
- YouTube動画の再生にはインターネット接続が必要です。
