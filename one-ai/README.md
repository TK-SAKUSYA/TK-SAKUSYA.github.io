# ONE AI

ChatGPT風のシンプルなAIチャットWebアプリです。

## 公開先
このアプリは既存の `TK-SAKUSYA.github.io` リポジトリの `one-ai/` に配置されています。既存のトップページは変更していません。

## AI接続
- Google Gemini APIをブラウザから直接呼び出します。
- 利用者自身のAPIキーを設定画面に入力する必要があります。
- APIキーはブラウザのlocalStorageに保存され、リポジトリには保存されません。
- GitHub Pagesの静的サイトだけでは秘密のAPIキーをサーバー側で保護できないため、キーをHTMLへ埋め込んでいません。
- 無料枠やモデルの提供状況・制限はGoogle側で変更される場合があります。

## 機能
- チャット作成・履歴・削除
- 会話のブラウザ内保存
- Geminiモデル選択
- モバイル対応レイアウト
- APIエラー表示

## 注意
このアプリの会話履歴とAPIキーは利用中のブラウザ内に保存されます。共有端末ではAPIキーを削除してください。
