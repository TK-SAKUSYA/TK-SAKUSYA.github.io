# Genesis Utopia（ジェネシス・ユートピア）

スマートフォン操作に対応した、キャラクター選択式アクションゲームの第1プレイアブル版です。

## プレイ
公開ページ： https://tk-sakusya.github.io/genesis-utopia/

## 第1版の内容
- 12キャラクターから選択
- ストーリー / バトルロイヤル / ボスラッシュ / トレーニングのモード選択UI
- タッチ操作用バーチャルスティック
- 攻撃とスペシャル攻撃
- 敵AI、HP、自動回復、スペシャルゲージ
- PCではWASD・矢印キーで移動、Spaceで攻撃、Shiftでスペシャル

## メモ
この版はゲームの操作感を確かめるためのプロトタイプです。モードごとの専用ルール、正式なステージ構成、キャラクターごとの固有挙動・数値調整、オンライン機能などは今後の開発項目です。
