# ONE TAP BOSS

スマートフォンのブラウザで遊べる、縦画面対応の軽量2Dボスラッシュゲームです。

## 遊び方
- **攻撃**：攻撃ボタンをタップ。PCでは A または Enter。
- **回避**：ボスの攻撃予告が表示されたら回避ボタンをタップ。PCでは Space または ↓。
- ボスを倒すと次のボスが登場します。ボスの種類に応じて攻撃予告とダメージが変化します。
- HPが0になるとゲームオーバー。撃破数・スコア・最高撃破数を表示します。

## 特徴
- HTML/CSS/JavaScriptのみで動作。外部ライブラリ・画像素材なし。
- タップ操作とPCキーボード操作に対応。
- 画面サイズに合わせた縦画面UI。
- 最高撃破数をブラウザのlocalStorageに保存。
- Service Workerによるキャッシュ対応。初回アクセス後、対応ブラウザではオフライン起動できます。

## ローカル実行
index.html をブラウザで開いてプレイできます。オフラインキャッシュの登録はHTTP(S)配信時に有効になります。
