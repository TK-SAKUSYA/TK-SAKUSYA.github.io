# Genesis Utopia

PC向けの2Dドット絵・見下ろし型RPGです。

## 操作
- 移動：WASD / 矢印キー
- マウス：フィールドをクリックした場所へ移動
- 調べる・会話：E / Enter / Space
- ワールドマップ：画面下の「ワールド」ボタン / M キー
- メニュー：Esc
- 戦闘コマンド：画面上のボタン、または数字キー 1〜5
- 全画面：画面右上の「全画面」ボタン

## ワールド
- WORLD 0：ムーラ村（道具屋・宿屋・村長）
- WORLD 1：はじまりの草原
- WORLD 2：灼熱の砂漠
- WORLD 3：静寂の雪原

## 現在の内容
- 4つのワールドと順次進行
- 村人との会話、道具屋、宿屋
- 通常モンスターとワールドボス
- ターン制コマンドバトル
- 攻撃・スキル・アイテム・防御・逃走
- 経験値、レベルアップ、ゴールド
- ローカル自動セーブと手動セーブ
- ウィンドウ表示・全画面表示

セーブデータはブラウザーの localStorage に保存されます。既存の初期版セーブデータは新しいワールド番号へ自動移行します。
