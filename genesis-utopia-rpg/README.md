# Genesis Utopia

PC向けの2Dドット絵・見下ろし型RPGの初期プレイアブル版です。

## 操作
- 移動：WASD / 矢印キー
- マウス：フィールドをクリックした場所へ移動
- 調べる・会話：E / Enter / Space
- メニュー：Esc
- 戦闘コマンド：画面上のボタン、または数字キー 1〜5
- 全画面：画面右上の「全画面」ボタン

## 現在の内容
- 草原・砂漠・雪原の3ワールド
- 通常モンスターとワールドボス
- ターン制コマンドバトル
- 攻撃・スキル・アイテム・防御・逃走
- 経験値、レベルアップ、ゴールド
- ローカル自動セーブと手動セーブ
- ウィンドウ表示・全画面表示

セーブデータはブラウザーの localStorage に保存されます。
