データのバックアップ・復元

キャラクター、作品、プロフィール、ギャラリー画像、ゴミ箱をまとめて保存できます。

データはこのブラウザ内（IndexedDB）に保存されます。ブラウザのデータ削除・端末変更に備えて、定期的にバックアップしてください。画像もJSONに含まれるため、画像が多い場合はファイルサイズが大きくなります。

保存について

このアプリはアカウント不要です。作成したデータは利用中のブラウザ内に保存され、他の利用者には共有されません。

※別の端末やブラウザへ移す場合は、JSONバックアップを使ってください。
