# 書いて生き残れ！

Three.js を使った、ブラウザで遊べる3Dサバイバルゲームの初期プロトタイプです。

## プレイ
GitHub Pages: https://tk-sakusya.github.io/write-survive/

## 操作
- PC: WASDで移動、Spaceでジャンプ、Shiftでダッシュ、マウスクリックで攻撃
- スマートフォン・タブレット: 左スティックで移動、右側のボタンでジャンプ・攻撃など
- ランダムで入力者に選ばれたら、画面中央の欄に単語や短いフレーズを入力

## 現在の実装
- Roblox風のブロック型3Dキャラクター
- アリーナ・草原・シティの3マップ
- プレイヤー1人＋BOT最大11体
- BOTの追跡・攻撃・文字入力
- ランダムな入力者選出と30秒の入力時間
- 文字に応じた実体化オブジェクト
- HP、自動回復、脱落、勝敗判定
- PCとタッチ端末向けの基本操作

## 技術
- HTML / CSS / JavaScript
- Three.js (CDN)

## プロトタイプについて
これは遊べる初期版です。仕様で決めた全機能が完成した最終版ではありません。装備ショップ、コイン、実績、復活、詳細な物理挙動、BOTの高度な判断、各種バランス調整などは今後のアップデート項目です。
