# 書いて生き残れ！ — Let's Write

Three.js を使った、ブラウザで遊べる3Dサバイバルゲームのプロトタイプです。

## プレイ
https://tk-sakusya.github.io/write-survive/

## 操作
- PC: WASDで移動、Spaceでジャンプ、Shiftでダッシュ、左クリックで攻撃
- PC視点: マウス右ボタンを押しながらドラッグで視点回転、ホイールでズーム
- スマートフォン・タブレット: 左スティックで移動、画面右側をドラッグして視点回転、右側ボタンでジャンプ・攻撃など
- ランダムで入力者に選ばれたら、画面中央の欄に単語や短いフレーズを入力

## 第2回アップデート「Let's Write」
- BOTの追跡・接近・距離調整・回避行動を改善
- Roblox風の右ドラッグ視点回転、ズーム、カメラ方向に合わせた移動
- プレイヤー/BOTの頭上に名前タグを表示
- 誰が何を書いたか、画面上部の書き込みフィードとキャラクター頭上の吹き出しで表示
- 草原・アリーナ・シティ、キャラクター、実体化オブジェクトのプロシージャルテクスチャを刷新
- 再戦時に前のマップオブジェクトが残る問題を修正

## 現在の主な機能
- Roblox風のブロック型3Dキャラクター
- アリーナ・草原・シティの3マップ
- プレイヤー1人＋BOT最大11体
- ランダムな入力者選出と30秒の入力時間
- 文字に応じた実体化オブジェクト
- HP、自動回復、脱落、勝敗判定
- PCとタッチ端末向けの基本操作

## 技術
- HTML / CSS / JavaScript
- Three.js 0.160.0 (CDN)

## プロトタイプについて
これは遊べる初期プロトタイプです。仕様で決めた全機能が完成した最終版ではありません。ショップ、コイン、実績、復活、ロビー、より高度なBOT判断やゲームバランス調整などは今後のアップデート項目です。
