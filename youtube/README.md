# YouTube

YouTube風のローカルWebアプリです。

## 使い方
- `index.html` をブラウザで開きます。
- 動画・投稿・プロフィールなどのデータはブラウザ内に保存されます。
- 動画ファイルはGitHubやYouTubeへアップロードされません。

## 第三回アップデート
- PC表示／モバイル表示の切り替え
- 高評価・低評価・共有・保存・ループ再生
- コメント、コメントへの高評価・低評価・返信
- AI風アカウントによる自動視聴・評価・コメント
- チャンネル分析画面

## 注意
これはYouTube公式サービスではなく、YouTube風のUIを持つ個人制作アプリです。AIアカウントの活動はアプリ内のシミュレーションであり、本物の人間や外部ユーザーではありません。動画・コメント・分析データは基本的に使用中のブラウザ内に保存され、他の人の画面には同期されません。ライブ配信の実配信や本物のYouTubeへの投稿機能は実装されていません。
